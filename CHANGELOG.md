# Changelog

## 0.3.1

Updated build: Pixel (default) and Modern in-game styles, switchable from the
Right Shift, main, and pause menus. Smooth corners and translucent surfaces in
Modern share the same layout as Pixel. Saved with profiles and presets.

Launcher and in-game menu redesign: charcoal surfaces, vivid pink accents, new
launch artwork, responsive module cards, category filters, clearer toggles, and
refreshed controls. Legacy launcher styling and README updated.

[Full 0.3.1 release notes](docs/releases/v0.3.1.md)
