# Blossom v0.2.4

- Zoom and scroll zoom respond in 80 ms instead of 250 ms.
- Zoom, sprint, sneak and Blossom-menu bindings sync with Minecraft Controls;
  module key editors support keyboard and mouse buttons.
- Blossom settings button fills the gap in the pause menu.
- Rounded buttons and panels throughout the client and launcher.
- Static/Dynamic FOV is one mode selector; conflicting modes cannot be enabled.
- Optional raw mouse input: Windows Raw Input and Linux XInput2/XWayland paths,
  focus/menu flushing, status display and vanilla fallback when unavailable.
- Redesigned launcher with separate online/offline cards, readable selected tabs,
  and a stationary progress bar with “Minecraft is running” after process start.
- Remembered Microsoft sign-in across restarts and updates. Sign in once on this
  version; older releases did not save credentials. Sign out removes the saved
  refresh token. Storage is owner-only, in the shared .blossom folder.
- Clean ZIP: only README and the two start scripts at the top level; support
  files are organized under app, licenses and checksums.

Download **blossom-0.2.4.zip** and extract the entire folder before starting.

74 core assertions, 49 launcher checks, eight vanilla transformations and Java 8
linkage pass. Launcher previews and the relocated Linux bootstrap were checked.
Live account refresh, physical raw input and graphical Minecraft acceptance
remain unverified in the build environment. This is a prerelease.
