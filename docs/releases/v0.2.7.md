# Blossom 0.2.7

- Add **Skins & capes** between Settings and Logs: current account skin, permanent local skin collection, thumbnails, rotating preview, Classic/Slim import and account-owned cape selection. The Play profile displays your skin's head.
- Add separate switches for verifying existing game files and Java. New downloads remain checksum-verified; Repair forces verification.
- Add **Disable hotbar scrolling**. Menus and zoom scrolling remain available.
- Add cape head/hat collision and remove directional face shading while keeping Minecraft lightmap lighting and Fullbright.
- Keep the sprint toggle through menus, server changes and restarts. Only the sprint key changes its latch.
- Add five module preset slots with explicit save/load and overwrite confirmation.
- Replace Blossom's flower with the new SVG, including launcher branding, game/legacy window icons and Linux desktop/Wayland application identity. The SVG is included in native ZIPs.
- Add **1.7 Visuals** with separate blocking, block-hit, sneak-camera, rod, bow, equip, eating/drinking, held-item position, damage, glint and optional always-swing settings. These affect rendering only; disabling the module restores vanilla rendering.

Download the Windows or Linux x64 ZIP. Existing settings, skins and installs are retained. The legacy launcher ZIP is also available, but the new account wardrobe is in the native launcher.

Automated checks cover Java core/cloth behavior, actual 1.8.9 transformations and JVM verification, Rust backend tests, browser UI fixtures and native Linux startup/IPC. Live Microsoft skin/cape changes and graphical Minecraft acceptance still require testing. Classic sprite transforms preserve vanilla maps and 3D models; they do not replace 1.8 textures or gameplay. See `docs/VALIDATION-0.2.7.md` for the test scope.
