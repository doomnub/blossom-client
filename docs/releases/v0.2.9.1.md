# Blossom 0.2.9.1

- Add a detailed benchmark ZIP with frame statistics, per-frame CPU/phase timings,
  memory/GC samples, nested workload sections and chunk-job/queue statistics.
- Separate main-thread chunk work from parallel worker time, and inclusive timing
  from self time; summarize the largest measured workloads.
- Run chunk uploads outside the producer queue lock.
- Cache HUD widths and refresh telemetry text at 20 Hz while keeping input
  indicators live every frame.

Start in Performance settings, return to the world, then capture for 60 seconds
or finish early. Files are saved under `blossom/benchmarks` in the game directory.
See docs/PERFORMANCE.md for interpretation and limits. CPU-side profiling does not
measure GPU execution or physical input latency. Real gameplay speedup remains
unmeasured.
