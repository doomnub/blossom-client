# Blossom 0.3.1

## Launcher redesign

- Charcoal surfaces with vivid pink accents, cleaner spacing and typography, consistent navigation icons, and original block artwork on the Play page.
- Improved compact-window layouts, focus indicators, and consistent styling across Settings, Skins & capes, Logs, and Changelog.
- Updated the legacy launcher's palette to match.

## Two in-game visual styles

- **Pixel** remains the default, preserving the current blocky Minecraft appearance.
- **Modern** uses smooth antialiased corners and translucent charcoal/pink panels, cards, controls, and rounded HUD backgrounds. Fonts, layouts, text metrics, and click targets stay consistent between styles.
- Switch instantly using **Style: Pixel / Modern** in the Right Shift module menu or the main/pause menus. The choice persists in profiles and presets; missing or invalid style settings default to Pixel.
- HUD backgrounds still respect the existing background toggle, opacity, and color settings. The launcher is unchanged by this switch.

**Updated 0.3.1 downloads:** this prerelease replaces the earlier redesign-only build with both in-game styles. Re-download the package if you installed the original 0.3.1.

## In-game menus

- Replaced the long module button list with a responsive card library featuring category filters, text search, previous/next pagination, and explicit enabled/disabled switches.
- Kept module settings separate from toggle targets; HUD editing, shared appearance controls, keybindings, backgrounds, and five preset slots remain accessible.
- Refreshed shared panels, buttons, and slider tracks/handles. Ordinary main-menu and pause-menu buttons now share the theme; specialized controls retain their behavior.
- Menu styling uses lightweight geometry without new gameplay background workers or blur shaders.

## Packaging and documentation

- Updated the README and release history for the current launcher and module set.
- Updated all launcher/client version labels and package metadata to 0.3.1.
- Start the CI virtual display before the D-Bus session so Linux desktop services inherit its display environment.

Linux and Windows native launchers and a separate legacy launcher are included.
Native archives contain only their own platform's startup script. Existing profiles,
module settings, skins, and worlds remain in their existing locations.

The redesign passed Java 8 core and menu target-layout checks and launcher browser
checks at 1120, 800, and 640 pixels wide. In-game graphical acceptance remains
pending; automated layout checks are not a substitute for gameplay verification.
