# Blossom 0.2.5 — native launcher and cape physics preview

- New Tauri 2 launcher with a Rust backend, pink Blossom interface, Play/Settings/Logs tabs, Microsoft device sign-in and refresh, offline mode, verified Minecraft/Java installation, repair, cancellation and live game logs.
- Reads existing launcher settings and installations; preserves unknown preferences. Unicode paths round-trip safely.
- Settings pages wrap in both directions. Empty potion HUD text is optional and off by default.
- Custom Cape and Cape Physics are separate modules. Configurable 120 Hz cloth simulation includes structural, shear and bending constraints, animated-body capsules, bounded spatial-hash self-collision, interpolation and distance/resolution limits.
- Hit Color, Particle Changer and passive Network Graph controls added.

Download the Windows or Linux x64 ZIP for the native launcher. Windows needs WebView2; Linux needs WebKitGTK 4.1. See the included README. The `legacy` ZIP retains the Swing launcher as a fallback while desktop acceptance is outstanding. The client JAR is still Java 8 bytecode.

Automated validation covers Java/transformer checks, cloth behavior, Rust settings and installer logic, fresh installs on Windows/Ubuntu, frontend behavior and native builds. Actual Microsoft sign-in, native desktop game launching, Fedora/Windows 11 acceptance and in-game rendering remain unverified here. Self-collision is bounded vertex/triangle projection, not complete continuous edge/edge collision; fast folds may intersect. This is a prerelease, not a claim of completed gameplay acceptance.
