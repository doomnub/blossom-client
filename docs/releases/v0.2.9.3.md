# Blossom 0.2.9.3

Linux stability update, launcher improvements and Now Playing HUD.

- Linux uses vanilla renderer scheduling and buffers by default while retaining
  Blossom modules. This rolls back suspect optimization hooks after reports that
  full safe mode avoids world-entry freezes. Saved profiles cannot re-enable them.
  This is a mitigation; the precise freeze cause and affected-hardware resolution
  are not yet confirmed.
- Automatically save bounded stall reports with thread stacks, heap/direct-buffer
  usage and GC counters under the instance's blossom/diagnostics directory.
- Add Now Playing HUD using Linux MPRIS or Windows media sessions, with album art,
  title, artist, progress and a rounded translucent panel. Linux requires Python 3
  and GLib/GIO; players must expose OS media sessions.
- Add Changelog below Logs in both launchers, showing the latest release notes.
- Linux native packages include only the Linux startup script; Windows native
  packages include only the Windows startup script. Universal legacy remains
  cross-platform.
- Rework generated item-model fronts and sides to address gaps, preserve
  transparent holes and bound complex geometry. Custom 3D models are unchanged.

Build, bytecode, geometry, launcher UI and OS media-adapter startup checks are
covered by automation. Real media playback and item appearance still require
in-game acceptance testing. Windows retains its existing renderer policy.
