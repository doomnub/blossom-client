# Blossom v0.2.2

- Each module now has **Visuals** and **Functionality** settings tabs. Appearance
  controls are separate from behavior/content options, with pagination for small
  GUI scales and a dedicated position-lock button.
- Added **Blossom settings** to the upper-right of Minecraft's main menu.
- Fixed toggle sprint reading the attack binding. It now holds the correct vanilla
  sprint binding while toggled, so sprint can resume after stopping. Vanilla
  movement restrictions remain in control; no speed or player-physics patch.
- FPS now defaults to **Current**, using Minecraft's built-in FPS counter. Choose
  **Average** in Functionality and optionally enable 1%/0.1% lows.
- Retains automatic Java 8 installation and offline launch.

Download **blossom-0.2.2.zip** and use the included start script.
48 core assertions, 43 launcher checks, five real vanilla bytecode transformations
and sprint-binding regression checks pass. Graphical gameplay acceptance remains
unverified in the build environment; this is a prerelease.
