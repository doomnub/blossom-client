# Blossom v0.2.3

- Toggle sprint stays toggled through menus, suspends input while menus are open,
  and resumes afterward with vanilla movement restrictions still in control.
- New FOV module: constant FOV or individual base, sprint, Speed I/II, slowness,
  flying and bow values, plus a dynamic-sprint switch.
- Zoom smoothly interpolates over 250 ms. Scroll while zoomed to change the level
  smoothly; each new hold resets to your configured default.
- Hide extra text/units on applicable HUDs, including ping and CPS.
- Potion effects can hide level 1 (enabled by default).
- All HUD visuals button changes size, colors, opacity and shadow across HUDs.
- More pink throughout module/settings/cape screens and the launcher, with clear
  button borders, hover states, panels and a subtle blossom accent.
- Retains automatic Java 8 installation and offline launch.

Download **blossom-0.2.3.zip**, extract it and use the included start script.

Validation: 72 core assertions, 43 launcher checks, six real vanilla bytecode
transformations and JVM linkage checks pass. Managed Java 8 install/reuse passes;
the Swing preview was inspected. Graphical Minecraft gameplay remains unverified
in the build environment, so this is a prerelease.
