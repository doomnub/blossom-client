# Blossom 0.3.0

- **XP Changer:** saved 0–100% hotbar fill slider. Actual XP and levels are unchanged.
- **Time Changer:** visual midnight-to-midnight control with 0.01-hour precision affecting sky, sun, moon, fog and sunlight. No world time writes or commands.
- **Custom Skies:** automatically reads OptiFine and MCPatcher sky resources from selected packs, including fades, rotation, blends, weather and location filters, and sun/moon overrides. Bounded background decoding and texture cleanup protect memory use.
- **Free Look:** tap Left Alt (under 0.25 seconds) to toggle, press again to turn off, or hold it for momentary orbit in third person without turning the player. The binding is configurable; holding restores the previous perspective on release. Camera orientation also updates chunk visibility and billboards.
- **Skybox fixes:** suppress vanilla lower-horizon geometry only while a custom layer is visible; keep all cube corners within low-distance clipping planes and inset atlas UVs to avoid neighbouring-face bleed.
- Building from the `scripts` directory now resolves game dependencies correctly.
- **New game icon:** a large pink block, distinct from the launcher flower.

Linux and Windows native launchers and the legacy launcher are included. Each native package includes only its own platform startup script.

Java 8 core tests, synthetic sky-resource fixtures and transformed-class verification passed. In-game graphical acceptance remains pending; these checks do not establish visual equivalence with OptiFine. See docs/CUSTOM-SKIES.md for supported features and resource limits.
