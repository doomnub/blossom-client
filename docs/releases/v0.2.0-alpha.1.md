# Blossom v0.2.0-alpha.1

First standalone Blossom launcher alpha, with the client embedded.

- Dark/pink Play, Settings and Logs interface; Java 8 selection, memory and window settings.
- Verified Minecraft 1.8.9/library/native/asset installation and repair.
- Microsoft device-code authentication implementation, entitlement check and direct game launch.
- In-memory sessions; game token passed through stdin rather than command-line arguments.
- Cape library import, rename, recoverable removal, preview and playback controls.
- PvP HUDs, editable styles and vanilla toggle-sprint/sneak controls.

Download **blossom-0.2.0-alpha.1.zip**, extract and read README.md. Individual
launcher and agent JARs plus SHA256SUMS.txt are also attached.

**Setup required:** This alpha does not supply a registered Microsoft application
ID. Configure a project-owned public-client ID with Minecraft service access;
use an existing authenticated launcher with the agent otherwise. Minecraft needs
Java 8. Launcher targets Windows/Linux x86_64; no game binaries are redistributed.

**Validation:** 43 core assertions, 21 launcher checks, four real 1.8.9 bytecode
transformations and JVM linking checks. Live authentication and graphical game
acceptance have not been completed. This is not the complete 70-section spec.
