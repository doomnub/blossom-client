# Blossom 0.2.7.1

Hotfix for the Java 8 startup crash in 0.2.7.

- Fix the window icon's `ByteBuffer.flip()` call to use the Java 8 `Buffer` signature. Icon preparation also falls back to the vanilla icon on linkage errors.
- Compile both Java components against the Java 8 API (`--release 8`), preventing newer-JDK API calls from slipping into Java 8 bytecode.
- Replace the old XML logging output layout with a shared plain-text console/rolling-file configuration. This fixes the missing Jackson `JsonGenerationException` errors while retaining the updated Log4j libraries, `logs/latest.log` and exception stack traces.
- Add actual Java 8 execution tests for icon pixels and logging, including the native installer's real classpath and configuration on Windows and Linux. Class verification alone did not exercise these failures in 0.2.7.

Replace the old launcher with the new Windows or Linux ZIP. Existing account, skin, preset and game data are reused; no reinstall or settings reset is required. The legacy launcher is also updated.

Public release version: **0.2.7.1**. Cargo, npm and Tauri use the equivalent internal SemVer build identifier `0.2.7+1`; launcher UI, tags, JARs and ZIPs use `0.2.7.1`.
