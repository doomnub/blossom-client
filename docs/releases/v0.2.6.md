# Blossom 0.2.6

- Fix native launcher packages loading the development localhost URL. Release builds now embed the frontend, with a build guard and a real Linux WebView/IPC smoke test.
- Smooth cape face shading and visible render-only thickness with sharp perimeter edges.
- Crouch-aware anchors/colliders, jacket/sleeve clearance and resolution-independent cape stretch limits.
- Connection-scoped ping resets and current-login-profile lookup; unmeasured remote latency shows an awaiting state.
- New Left Hand module, including local third-person held items and correct left-arm skin. Maps retain their readable two-handed rendering.
- New Hit Tilt slider (0–200%, including no tilt).
- Stop unnecessary disabled-module sampling, sorting, decoding, uploads and network observation.

Download the Windows or Linux x64 ZIP. Existing settings and installs are reused. The legacy ZIP remains available.

Automated checks cover core behavior, cloth, actual vanilla bytecode hooks, Java verification, native builds and frontend/native startup. In-game visual acceptance, live sign-in and Fedora/Windows 11 gameplay still need testing. See docs/VALIDATION-0.2.6.md for exact limits.
