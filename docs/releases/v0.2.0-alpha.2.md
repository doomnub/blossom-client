# Blossom v0.2.0-alpha.2

Adds **Play offline**: enter a local username and launch without signing in or
configuring a Microsoft application ID. Microsoft sign-in remains available.

- Saved offline username and stable vanilla-compatible offline UUID.
- Complete installations reuse verified files without a network connection.
- Clearer Fedora graphical-runtime error and setup instructions.
- 43 core assertions, 32 launcher checks, real 1.8.9 bytecode verification,
  and a complete cached-install check with an unreachable HTTP proxy passed.

Download **blossom-0.2.0-alpha.2.zip**, extract it, select Java 8 in Settings,
and use **Play offline**. First installation or repair needs internet. Servers
that require authenticated accounts, including Hypixel, still require Microsoft
sign-in. Offline and online identities have different UUIDs/player data.

Windows/Linux x86_64 alpha. Graphical gameplay and live sign-in remain unverified.
