# Blossom 0.2.10.1

Bedwars-focused rendering and allocation improvements.

- Batch fancy-cloud cells while preserving vertex data, ordering and depth/color
  pass boundaries. Use vanilla's existing buffer with bounded batches.
- Cache formatted chat text within each game tick, with hard entry/character limits
  and invalidation on layout/message changes. Drawing and interaction remain live.
- Cull offscreen billboard particles using conservative interpolated bounds and
  the current camera. Specialized particle renderers and simulation stay unchanged.
- Add independent Performance switches for cloud batching, chat caching and particle
  culling. Turning Performance off restores their vanilla paths.
- Add an optional support-corner frustum experiment, off by default because synthetic
  timings did not show a consistent improvement.
- Improve detailed benchmark attribution for chat, weather, particles, nearby chunk
  rebuilds and camera-section visibility scans.
- Keep the older Linux renderer scheduling/buffer optimization group disabled.

Build, Java 8 linkage, cloud vertex equivalence, bounded caches and particle bounds
have automated coverage. The synthetic cloud fixture reduces 128 submissions to 4;
this is not a measured gameplay FPS gain. On-device visual and performance validation
is still needed. Private benchmark files and measurements are not distributed.
