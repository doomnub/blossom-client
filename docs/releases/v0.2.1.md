# Blossom v0.2.1

Java 8 now installs automatically. Extract **blossom-0.2.1.zip** and run
`bash start-blossom.sh` on Linux or `Start-Blossom.bat` on Windows.

- Downloads the matching 64-bit Azul Zulu Java 8u504 runtime, verifies its SHA-256,
  and installs it under your user folder's `.blossom/runtimes` directory.
- Starts Blossom using that runtime, with no preinstalled Java required. Linux
  uses Python 3; Windows uses built-in PowerShell. No admin rights needed.
- Remembers the exact Java executable for Minecraft and reuses it offline.
- Settings offers automatic management, Install / check Java 8, or a custom path.
- Preserves offline launch without an account or Microsoft application ID.
- 43 core assertions and 43 launcher checks, plus real runtime installation and
  offline-reuse checks.

First installation requires internet. Windows/Linux x86_64 only. Microsoft
sign-in still needs a registered application ID for authenticated servers.
Graphical Minecraft gameplay remains unverified, so this is a prerelease despite
the shorter version number. Future versions increment by one patch: 0.2.2 next.
